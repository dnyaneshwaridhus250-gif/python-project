# Student Performance Analytics System

Professional frontend project built using HTML5, CSS3 and Vanilla JavaScript.

## Features
- Responsive professional dashboard
- Student records table
- Search students
- Add/delete student records
- Total and average calculation
- Pass-rate calculation
- Subject performance bars
- Performance summary
- Automatic insights
- CSV report download
- No React, Angular, Vue, Bootstrap or Tailwind

## Run
Open `index.html` in a browser.

## Academic Stack
The original project brief specifies Python, NumPy and Pandas for the analytics concepts. This website provides the professional frontend presentation of the system. A Python/Pandas backend can be connected later if required.
